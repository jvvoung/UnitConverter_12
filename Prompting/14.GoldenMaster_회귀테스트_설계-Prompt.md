| # | 항목 | 내용 |

## Turn 1 — Golden Master 회귀 테스트 설계·구현

### User

```
[P] 회귀 테스트(Approval/Golden Master) 설계 전문가입니다.
[C] C++17, CMake, Catch2
[T] UnitConverter 출력 기반 Golden Master 기준 파일을 생성해줘.

    1) 기준 출력(tests/golden_master_expected.txt) 생성/보관 전략
       입력 시나리오 4개:
         "meter:2.5" / "feet:1.0" / "yard:1.0" / "meter:0.0"
       캡처 방식: stdout 리디렉션: ./UnitConverter < input.txt > actual.txt
       생성 후: git add tests/golden_master_expected.txt  (버전 관리 필수)

    2) approve 패턴 적용:
       - 기준 파일 없으면 → 현재 출력을 기준으로 자동 생성
       - 기준 파일 있으면 → actual vs expected 문자열 비교
       - 불일치 시: diff 출력 후 테스트 FAIL

    3) 기준 파일 구조:
       [meter:2.5]
       2.5 meter = 8.202100 feet
       2.5 meter = 2.734025 yard
       ---
       [feet:1.0]
       ...

[F] tests/golden_master_expected.txt 파일 내용 + 생성 스크립트
```

### Assistant (산출 요약)

**신규 파일**:

| 파일 | 역할 |
|------|------|
| `tests/golden_master_expected.txt` | Golden Master baseline (4 시나리오) |
| `tests/helpers/golden_master.hpp` | 캡처·6dp 정규화·approve·diff |
| `tests/golden_master_tests.cpp` | Catch2 TC 2건 |
| `scripts/generate_golden_master.ps1` | CLI 캡처 baseline 생성·`-Approve` |

**수정 파일**:

| 파일 | 변경 |
|------|------|
| `CMakeLists.txt` | `unit_converter_golden_master_tests` · `unit_converter_cli` 의존 |

**Catch2 TC**:

| TEST_CASE | 태그 | 검증 |
|-----------|------|------|
| `golden_master_cli_regression_matches_expected` | `[golden][regression][approval]` | CLI stdout ↔ expected Approval |
| `golden_master_engine_baseline_document` | `[golden][regression]` | Engine 문서 구조·대표 수치 |

**구현 핵심**:

- Windows CLI 캡처: `cmd /c "unit_converter_cli.exe < input.txt > output.txt"`
- 프롬프트+첫 변환행 동일 줄 → `): ` 이후 추출
- 동일 source unit 행 제외 · value token은 시나리오 입력 유지(`1.0`)
- CRLF → LF 정규화 후 문자열 비교
- `meter:0.0`: CLI E2E 허용 · Engine TC는 `ValueValidator` 거부 — 분리 처리

**현재 baseline** (레거시 CLI stdout, 6dp):

| 시나리오 | 변환행 |
|----------|--------|
| `meter:2.5` | `8.202100 feet` · `2.734020 yard` |
| `feet:1.0` | `0.304800 meter` · `0.333332 yard` |
| `yard:1.0` | `0.914403 meter` · `3.000010 feet` |
| `meter:0.0` | `0.000000 feet` · `0.000000 yard` |

**검증**:

```powershell
cmake --build build_cov --target unit_converter_golden_master_tests unit_converter_cli
ctest --test-dir build_cov -R golden --output-on-failure
# 기대: 2/2 PASS (#50~#51)

.\scripts\generate_golden_master.ps1 -BuildDir build_cov
# 기대: Golden master matches expected baseline.
```

**CLI vs Catalog 갭** (GM-GAP-01):

- yard `meter:2.5`: CLI **2.734020** vs Catalog Engine **2.734034** — DEF-002 연동 후 `-Approve` 필요

**PowerShell**: `&&` → **`;`** · Windows redirect는 **`cmd /c`** 필수
