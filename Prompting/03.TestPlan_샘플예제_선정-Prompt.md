## Turn 2 — 테스트 플랜 샘플 예제 1건 선정

### User

```
@c:\DEV\UnitConverter_12\ @README.md @docs/PRD.md 참고하여
테스트 플랜 작성을 위한 샘플 예제 1개를 선택해줘.

선택 기준:
1. README의 기본 요구사항에 명시된 핵심 변환 기능
2. 비즈니스 로직(1 meter = 3.28084 feet, 1 meter = 1.09361 yard)을 직접 검증
3. 정상 경로(happy path)와 경계값 모두 포함 가능한 기능

선택한 예제에 대해 다음을 명시하라:
- 선택한 기능 이름 (예: meter → feet 변환)
- README 요구사항 번호 (예: 기본 요구사항 4번)
- 입력 예시: "meter:2.5"
- 기대 출력: "2.5 meter = 8.202100 feet"
- 이 예제를 선택한 이유 2줄

코드 작성 금지. 선택 결과 문서만 출력.
```

### Assistant (산출 요약)

- `README.md`, `docs/PRD.md`, `docs/requirements.md` 교차 확인
- **선정 기능**: meter 기준 CONVERT — table 출력 (meter → feet/yard)
- **근거**: requirements **기본 1·4**, PRD **AC-02**, Background 규칙 1·2
- **입력**: `meter:2.5`
- **기대 출력**: PRD §6.2 table 1dp half-up 기준 (요청 예시 `8.202100`과 구분)
  - `2.5 meter = 8.2 feet` / `2.5 meter = 2.7 yard`, exit `0`, stderr 빈
- **확장 시나리오**: `meter:-2.5`, `meter:0` (POL-NEG), Domain raw ≈ 8.2021 / 2.7340
- **선정 이유 2줄**: Golden·비즈니스 로직 직접 대응 + 정상/경계 동일 플랜 묶음
- **산출**: 대화 응답 (코드 없음)
