## Turn 1 — DecayingUnit Bonus RED 테스트 작성

### User

```
프로젝트: @c:\DEV\UnitConverter_12\ 

신규 기능 RED 테스트를 작성하라. (구현 금지)

기능 설명:
  registerUnit("cubit", 0.4572)  // 1 cubit = 0.4572 meter
  convert("cubit", 1.0, "meter") == 0.4572 (오차 1e-5)
  convert("meter", 1.0, "cubit") == 1.0/0.4572 ≈ 2.1872 (오차 1e-5)
  convert("cubit", 1.0, "feet")  == 0.4572 * 3.28084 ≈ 1.4997 (오차 1e-5)

제약:
  - Item 구조체(UnitConverter.cpp의 기존 변환 로직) 수정 금지
  - 음수 비율 등록 시 예외 발생 (비율 > 0 강제)

테스트 케이스 (최소 5개):
  BT-01: registerUnit("cubit", 0.4572) 후 cubit→meter 변환
  BT-02: registerUnit 후 meter→cubit 역변환
  BT-03: registerUnit 후 cubit→feet 교차 변환
  BT-04: 음수 비율 등록 → std::invalid_argument 발생
  BT-05: registerUnit 후 convertAll("cubit", 1.0) → 전 단위 반환
  BT-06: 기존 meter→feet 결과 불변 (회귀 보호)

테스트 마킹: TEST_CASE("감쇠 단위 변환", "[bonus]") { REQUIRE(...); }

산출물: src/DecayingUnit.cpp + tests/test_decaying_unit.cpp (실패 상태)
```

### Assistant (산출 요약)

- **`src/DecayingUnit.hpp`**: `DecayingUnit` API — `registerUnit`, `convert`, `convertAll` (pimpl, move-only)
- **`src/DecayingUnit.cpp`**: anonymous `Item { name, meters_per_unit }` + 기본 3단위(meter/feet/yard) 스켈레톤
  - RED 스텁: `registerUnit` no-op · `convert` → `0.0` · `convertAll` → `{}`
  - **Item은 본 파일 내부만** — `UnitConverter.cpp`·BCE Domain 미수정
- **`tests/test_decaying_unit.cpp`**: `TEST_CASE("감쇠 단위 변환", "[bonus]")` + SECTION BT-01~06
  - `WithinAbs` ±1e-5 · BT-04 `std::invalid_argument`
  - 헬퍼 `makeConverterWithCubit()`
- **`CMakeLists.txt`**:
  - `unit_converter_decaying` 라이브러리
  - `unit_converter_bonus_tests` + `catch_discover_tests`
  - MSVC `/utf-8` (한글 TEST_CASE C2001 방지)
- **RED 검증**:
  ```powershell
  cmake --build build --target unit_converter_bonus_tests
  .\build\Debug\unit_converter_bonus_tests.exe
  # test cases: 1 failed | assertions: 6 failed (의도적)
  ```
- **BCE 격리**: `unit_converter_domain` 등 기존 타깅 **미변경** · Domain `registerUnit` TC 유지
