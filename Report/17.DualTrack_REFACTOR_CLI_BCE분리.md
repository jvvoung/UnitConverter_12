## 1. Executive Summary

[RPT-12](./12.DualTrack_TDD_GREEN_증분구현.md) 이후 **미연동 상태**였던 레거시 CLI(`UnitConverter.cpp`)를 Dual-Track REFACTOR 계획에 따라 **7개 Conventional Commit**으로 BCE 레이어에 위임하였다. 매 커밋 후 **Golden Master 4/4 PASS** 및 BCE·Dual-Track 회귀(의도적 RED 1건 제외)를 유지하였다.

| 구분 | REFACTOR 전 | REFACTOR 후 |
|------|-------------|-------------|
| `UnitConverter.cpp` | 53줄 단일 `main()` — 파싱·if-else·매직 넘버·출력 혼재 | **47줄 Thin Controller** — I/O·오케스트레이션만 |
| 단위 분기 | `if (unit == "meter")` … 체인 | `UnitCatalog` Map 조회 |
| 변환 비율 | `3.28084` / `1.09361` 인라인 4곳 | `domain/conversion_ratios.hpp` + `bootstrap_legacy_cli_catalog()` |
| 변환 로직 | `main()` 인라인 | `legacyCliConvert` / `legacyCliConvertAll` |
| 입력 파싱 | `main()` 인라인 `find(':')` | `InputParser::parseConvertLine` |
| 출력 포맷 | `cout` 직접 연결 | `CliOutputFormatter::formatLine` |
| Golden Master | 4/4 PASS | ✅ **4/4 PASS 유지** |

| DEF-002·003 | Open | **Open** (의도적 — PRD 계약 전환은 후속) |

**핵심 결론**: 레거시 CLI는 **구조만 BCE로 분리**되었고, **6dp·3행·0 허용** 골든 마스터 계약은 그대로이다. PRD AC-02(1dp half-up)·POL-NEG(DEF-003)는 `TableFormatter`·`ValueValidator` 연동 **후속 M2** 대상이다.

## 4. REFACTOR 전후 아키텍처

### 4.1 ECB / Dual-Track 배치 (최종)

```text
[Boundary] UnitConverter.cpp::main
    │  prompt + getline
    ▼
[Boundary] InputParser::parseConvertLine
    │  unit, value, value_token
    ▼
[Boundary] CliErrorMessages (ParseErrorCode / unknown unit)
    ▼
[Domain]   UnitCatalog (bootstrap_legacy_cli_catalog)
[Domain]   legacyCliConvert / legacyCliConvertAll
    ▼
[Boundary] CliOutputFormatter::formatLine → cout
```

## 6. 커밋별 상세

### 6.1 Track B — Domain / Logic

| ID | 변경 전 문제 | 변경 후 |
|----|-------------|---------|
| **R-L1** | `if (unit == "feet")` … OCP 위반 | `catalog.has(unit)` + `metersPerUnit` |
| **R-L2** | 비율 리터럴 분산 | `domain/conversion_ratios.hpp` + `bootstrap_legacy_cli_catalog()` |
| **R-L3** | meter 허브 수식이 `main()`에 분산 | `legacyCliConvert(from, value, to)` 단일 공식 |
| **R-L4** | 3개 `cout` 수동 연결 | `legacyCliConvertAll` + `legacyCliDisplayUnitOrder()` 순회 |

**변환 공식 (단일 경로)**:

```text
meters = value × metersPerUnit(from)
result = meters ÷ metersPerUnit(to)
```

### 6.2 Track A — UI / Boundary

| ID | 변경 전 문제 | 변경 후 |
|----|-------------|---------|
| **R-U1** | `find(':')`·`substr`·`stod`가 `main()`에 인라인 | `InputParser::parseConvertLine` |
| **R-U2** | 에러 문자열 산재 | `CliErrorMessages` + `InputParser::formatErrorMessage` |
| **R-U3** | 출력 포맷이 `main()`에 결합 | `CliOutputFormatter::formatLine` |

**에러 메시지 계약 (유지)**:

| 상황 | stderr |
|------|--------|
| `:` 없음 | `Invalid format. Use unit:value (ex: meter:2.5)` |
| 숫자 아님 | `Invalid number: {token}` |
| 미지원 단위 | `Unknown unit: {unit}` |

## 13. 결론

레거시 CLI `UnitConverter.cpp`에 대한 **Dual-Track REFACTOR 7건**을 완료하였다. Domain Track(R-L1~L4)은 UnitRegistry·상수·meter 허브·`convertAll`을 분리하였고, Boundary Track(R-U1~U3)은 파싱·에러·출력을 분리하였다. **Golden Master 4/4**와 BCE 회귀를 유지하면서 **외부 계약을 변경하지 않았다**. DEF-002·003 및 PRD AC-02/AC-01 정합은 **M2 계약 전환**으로 이관한다.
