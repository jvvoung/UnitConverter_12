## 5. 계약 API (선언만)

### 5.1 `ConversionApplicationService` (Track A)

```cpp
enum class OutputFormat { Table, Json };

class ConversionApplicationService {
public:
    ConversionApplicationService();
    std::string convert(const std::string& input);
    std::string convert(const std::string& input, OutputFormat format);
};
```

- **입력**: `std::string` `"unit:value"`
- **출력**: `"2.5 meter = 8.202100 feet"` 또는 JSON
- **예외**: `std::invalid_argument`

### 5.2 `UnitConverterLogic` (Track B)

```cpp
class UnitConverterLogic {
public:
    static void resetToDefaults();
    static double convert(const std::string& from, double value, const std::string& to);
    static std::map<std::string, double> convertAll(const std::string& from, double value);
    static void registerUnit(const std::string& name, double ratio_to_meter);
    static void loadConfig(const std::string& path);
};
```

- **비율**: `1 meter = 3.28084 feet`, `1 meter = 1.09361 yard` (기본값)
- **정밀도**: convert ±1e-5

## 7. 기존 BCE·레거시와의 관계

### 7.1 BCE vs RED 계약 API

| RED 계약 | 기존 BCE 대응 | 갭 |
|----------|--------------|-----|
| `UnitConverterLogic::convert` | `ConversionEngine::convert` | ✅ 동일 개념 — **파사드 미구현** |
| `UnitConverterLogic::convertAll` | `ConversionEngine::convertAll` | ✅ 동일 — 파사드 미구현 |
| `UnitConverterLogic::registerUnit` | `UnitCatalog::registerUnit` | ✅ 동일 — 파사드 미구현 |
| `UnitConverterLogic::loadConfig` (fallback) | `ConfigLoader::loadFromFile` (throw) | ⚠️ **TC-B-06**: invalid path 시 **예외 vs 기본값 유지** 상충 |
| `ConversionApplicationService` | `InputParser` + `TableFormatter` + Engine | ⚠️ **통합 서비스 미존재** |
| `std::invalid_argument` | `ConvertParseResult` / exit+stderr (PRD) | ⚠️ README 학습용 vs PRD stderr — GREEN 시 매핑 필요 |
