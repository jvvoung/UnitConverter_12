## 3. Golden Master 설계

### 3.1 입력 시나리오 (4건)

| # | 입력 | 용도 |
|---|------|------|
| 1 | `meter:2.5` | Golden·AC-02 대표 입력 · test_plan 앵커 |
| 2 | `feet:1.0` | 역변환(feet 허브) E2E |
| 3 | `yard:1.0` | 역변환(yard 허브) E2E |
| 4 | `meter:0.0` | 영(0) 경계 — CLI는 허용, Domain Validator는 거부 |

### 3.2 기준 파일 구조

```text
[meter:2.5]
2.5 meter = 8.202100 feet
2.5 meter = 2.734020 yard
---
[feet:1.0]
...
---
```

| 규칙 | 내용 |
|------|------|
| 섹션 헤더 | `[unit:value]` — 시나리오 입력 그대로 |
| 변환 행 | `{value_token} {source_unit} = {target_6dp} {target_unit}` |
| 구분자 | 시나리오 블록마다 `---` |
| 동일 단위 제외 | source unit 행 미포함 (예: `meter:2.5` → feet·yard만) |
| 소수 표기 | **6자리 고정**( `%F6` / `std::fixed` + `setprecision(6)`) |
| 줄바꿈 | LF(`\n`) 정규화 — Windows CRLF 비교 오류 방지 |

### 3.3 stdout 캡처 방식

**수동·스크립트 공통**:

```text
unit_converter_cli.exe < input.txt > actual.txt
```

**Windows 구현** (C++ / PowerShell):

```text
cmd /c "unit_converter_cli.exe < input.txt > output.txt"
```

**파싱 특수 처리**:

| CLI 출력 특성 | 처리 |
|---------------|------|
| 프롬프트 + 첫 변환행 동일 줄 | `): ` 이후만 추출 |
| 프롬프트 문구 | `Insert value for converting...` 제거 |
| CRLF | `\r` 제거 후 비교 |
| value token | CLI 표기(`1`)가 아닌 **입력 시나리오 token**(`1.0`) 유지 |

### 3.4 Approval 패턴

```text
┌─────────────────────────────────────┐
│  buildGoldenDocumentFromCli()       │
│  (4 시나리오 stdout 캡처·정규화)      │
└──────────────┬──────────────────────┘
               ▼
     golden_master_expected.txt 존재?
          /              \
        No               Yes
         │                │
         ▼                ▼
   actual을 기준으로     expected == actual?
   파일 자동 생성              /        \
   (baseline approve)        Yes        No
                              │          │
                              ▼          ▼
                           PASS      unified diff
                                       + FAIL
```

**C++ API** (`tests/helpers/golden_master.hpp`):

- `approveGoldenMaster(path, actual, auto_create_baseline)`
- `makeUnifiedDiff(expected, actual)` — 불일치 시 `-` / `+` diff 출력

**스크립트 Approve**:

```powershell
.\scripts\generate_golden_master.ps1 -BuildDir build_cov -Approve
git add tests/golden_master_expected.txt
```
