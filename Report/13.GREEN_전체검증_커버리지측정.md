```powershell
ctest --test-dir build -C Debug -R "green|valid_input|input_without|negative_value|unknown_unit|output_preserves|zero_value|convert_meter|convert_feet|convert_all|register_unit|load_config" --output-on-failure
```

### 3.3 커버리지 측정 (MinGW + lcov)

MSVC는 gcov 미지원 → MinGW 별도 빌드 디렉터리 `build_cov` 사용.

```powershell
$env:Path = "C:\mingw64\bin;C:\ProgramData\chocolatey\bin;" + $env:Path
cmake -S . -B build_cov -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Debug -DENABLE_COVERAGE=ON
cmake --build build_cov -j 4
ctest --test-dir build_cov --output-on-failure

lcov --directory build_cov --zerocounters
ctest --test-dir build_cov --output-on-failure
lcov --capture --directory build_cov --output-file build_cov/coverage.info --ignore-errors gcov
lcov --extract build_cov/coverage.info "*/src/domain/*" -o build_cov/domain.info --ignore-errors gcov
lcov --extract build_cov/coverage.info "*/src/boundary/*" -o build_cov/boundary.info --ignore-errors gcov
lcov --summary build_cov/domain.info
lcov --summary build_cov/boundary.info
```

**레거시 `UnitConverter.cpp` gcov** (CLI 1회 실행):

```powershell
echo "meter:2.5" | .\build_cov\unit_converter_cli.exe
gcov -b -o CMakeFiles/unit_converter_cli.dir CMakeFiles/unit_converter_cli.dir/UnitConverter.cpp.gcda
```

## 7. 부수 변경 사항

MinGW 커버리지 빌드 시 `InputParser.cpp`에서 `std::isfinite` 컴파일 오류 발생 → `#include <cmath>` 1줄 추가.

| 파일 | 변경 | 사유 |
|------|------|------|
| [src/boundary/InputParser.cpp](../src/boundary/InputParser.cpp) | `#include <cmath>` 추가 | MinGW(GCC 15.2) `std::isfinite` 가용 — MSVC는 `<sstream>` transitive include로 통과 |

> 본 변경은 **커버리지 측정을 위한 이식성 수정**이며, Dual-Track GREEN 동작·ctest 결과에 영향 없음 (MSVC 빌드 재검증: 48/49 유지).
