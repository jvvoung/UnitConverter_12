## 1. Executive Summary

[03.TestPlan_샘플예제_선정.md](./03.TestPlan_샘플예제_선정.md)에서 선정한 앵커 예제 **`meter:2.5` CONVERT(table)** 를 기준으로, Catch2·CMake·gcov/lcov를 포함한 **공식 테스트 계획서**를 `docs/test_plan.md`에 작성하였다.

| 구분 | 03 선정 보고 시점 | 본 작업 후 |
|------|-------------------|------------|
| 샘플 예제 | `meter:2.5` 1건 선정·근거 정리 | 동일 앵커로 **전체 TC·경계·커버리지** 명세화 |
| 테스트 플랜 문서 | §8 권장 작업 #3 “선택: docs/” | **`docs/test_plan.md` v1.0 완료** |
| Catch2 TC 목록 | §4.4 시나리오 4건 요약 | **P0~P3 우선순위 17건** + BV 6건 + EX 16건 |
| 커버리지 전략 | PRD §4.3 인용만 | **gcov/lcov 측정 절차·게이트** 포함 |

**핵심 결론**: 선정 보고서 §4.4의 “테스트 플랜 초안”이 **실행 가능한 TC ID·Given-When-Then·측정 전략**으로 구체화되었으며, 다음 실무 단계는 본 계획서 §10 권장 작업 #1 — **CMake + Catch2 골격 및 P0 RED TC 이식**이다.

## 6. 커버리지·측정 전략 (요약)

### 6.1 게이트 (PRD §4.3)

| 레이어 | Line | Branch |
|--------|------|--------|
| **Domain** | ≥ 95% | ≥ 90% |
| **Boundary** | ≥ 90% | **≥ 85%** |
| 전체 | ≥ 88% | — |

### 6.2 gcov / lcov / UnitConverter.cpp

| 단계 | 명령·도구 | 용도 |
|------|-----------|------|
| 빌드 | `cmake -DENABLE_COVERAGE=ON` | `--coverage -O0 -g` |
| 실행 | `ctest --test-dir build` | `.gcda` 생성 |
| 레거시 baseline | `gcov -b UnitConverter.cpp` | BCE 이전 단일 파일 Line/Branch |
| 집계 | `lcov --capture` + `--extract '*/src/domain/*'` | Domain 95% 게이트 |
| 리포트 | `genhtml` → `build/coverage_html` | AC-06 제출물 |

**RED 단계 기대**: 레거시 `UnitConverter.cpp`는 POL-NEG·1dp 분기 **미커버** — GREEN 후 동일 TC 재실행으로 상승 확인.
