### 5.2 `convert()` 최소 구현

```cpp
double convert(const std::string& from_unit, double value, const std::string& to_unit) {
    if (from_unit == "meter" && to_unit == "feet") {
        return value * conversion_ratios::METER_TO_FEET;
    }
    return 0.0;  // 미구현 분기 — TC-B-02~ 등 후속 GREEN
}
```
